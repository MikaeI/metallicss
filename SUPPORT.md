# Support

MetalliCSS is maintained as an open-source project without a guaranteed support
service or response time.

## Start here

1. Read the [README](README.md), especially the 5.0.0 candidate notice and
   browser expectations.
2. Reproduce the behavior in a minimal HTML page or the repository demo: run
   `npm ci`, then `node scripts/serve.mjs`, and open
   <http://127.0.0.1:4173>. The public Pages deployment is not yet enabled.
3. Search existing issues for the error message, browser, and feature involved.

## Where to ask

- **Confirmed or reproducible bug:** use the repository's bug report form.
- **Concrete feature proposal:** use the feature request form and describe the
  user problem before the proposed implementation.
- **Usage question:** use GitHub Discussions when it is enabled. If Discussions
  is unavailable, open an issue only when the documentation is incorrect or
  missing; include the smallest example that demonstrates the gap.
- **Security concern:** follow [SECURITY.md](SECURITY.md) and report it privately.
- **Conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and do not
  disclose sensitive details publicly.

## What to include

Good support requests contain:

- MetalliCSS version or the commit used from `main`.
- Installation and import method.
- Browser version and operating system.
- Minimal HTML, CSS, and JavaScript that reproduces the behavior.
- Expected and actual results, including console errors.
- Relevant Content Security Policy and framework lifecycle details.
- Screenshots or recordings for visual issues.

Do not post credentials, private URLs, personal data, npm tokens, or unreleased
vulnerability details.

## Support boundaries

The latest published major version and current development branch receive
attention first. Maintainers may ask you to reproduce an issue without a
framework or third-party component. Integration-specific questions are welcome
when they reveal a lifecycle or documentation problem in MetalliCSS, but the
project cannot provide general application consulting.
